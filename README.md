El Quinzet (enllaçat a la web de càlcul ràpid) és una aplicació web educativa i interactiva basada en el conegut Mètode El Quinzet, dissenyada per a l'alumnat de Primària i Secundària amb l'objectiu d'automatitzar les operacions aritmètiques elementals a través de la pràctica de la rapidesa de càlcul mental.

Funcionalitats i Característiques Principals
El Mètode de Càlcul Ràpid: Estructurat per entrenar l'agilitat i la fluïdesa en el càlcul mitjançant proves cronometrades.

Proves Contrarellotge (2 minuts):

L'usuari disposa exactament de 120 segons per resoldre una sèrie nombrosa d'operacions distribuïdes en columnes (generalment organitzades per columnes A, B, C i D).

Permet saltar-se operacions si s'embussen per maximitzar el nombre d'encerts.

Criteris de Progrés (Regla d'or d'El Quinzet):

Menys de 15 encerts: Es recomana baixar de nivell per consolidar bases.

50 encerts o més (l'objectiu ideal): Permet o recomana pujar de nivell.

Panell de Resultats i Historial:

Mostra el total d'operacions correctes, contestades i errors un cop finalitzat el temps.

Desa un historial d'intents per poder comparar el progrés diari i superar rècords personals.

Personalització: Selecció de paràmetres i nivells de dificultat adaptats a diferents edats i cicles educatius.

Objectiu Educatiu
L'aplicació digitalitza un mètode clàssic de l'escola catalana (creat originalment pel col·lectiu El Quinzet), transformant el paper en una eina web fluida, autònoma i motivadora per millorar el càlcul mental diari a l'aula o a casa.
